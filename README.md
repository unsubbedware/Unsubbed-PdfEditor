# Unsubbed PDF Editor — downloads

A local, offline desktop PDF editor: fill forms, sign, reorganise and merge
pages. No cloud upload, no account.

**Download:** see the [Releases](../../releases) tab, or get it from
[unsubbedware.com/apps/pdf-editor](https://unsubbedware.com/apps/pdf-editor).

Windows 10/11, 64-bit. The installer isn't code-signed yet, so Windows
SmartScreen shows a prompt the first time — choose *More info → Run anyway*.
Each release lists a SHA-256 for the installer.

Licensed under the Unsubbedware EULA (bundled with the app). This repo holds
released builds only; the source is not public.
